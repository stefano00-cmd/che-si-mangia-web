# Che si mangia? – versione web (iPhone / qualsiasi browser)

## Metterla online con GitHub Pages (gratis)
1. Su github.com crea un repository **pubblico** (es. `che-si-mangia-web`).
2. Carica tutto il contenuto di questa cartella (Add file → Upload files).
3. Settings → Pages → "Deploy from a branch" → Branch `main`, cartella `/ (root)` → Save.
4. Dopo 1-2 minuti l'indirizzo è `https://TUO-NOME.github.io/che-si-mangia-web/`.

## Sull'iPhone
Apri l'indirizzo in Safari → Condividi → **Aggiungi a Home**. Si apre a schermo intero come un'app.
Crea l'account dalla schermata iniziale: i dati restano sincronizzati anche se la web app viene reinstallata.
